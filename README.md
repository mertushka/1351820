`1351820.xyz` is a personal index page built around a small encoded identity.

The domain is not just a number.  
It is a cipher.

```text
13 5 18 20
 m e  r  t
```

The page begins with the numeric form, lets the letters surface one by one, and resolves into a name. Once `mert` is found, `ushka` slides in to complete the full nickname.
